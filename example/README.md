# Example app

This example demonstrates the main usage patterns of `thing_sheet` in a small Flutter app.

## Included examples

- A popup dialog created with `ThingSheet.showPopUp(...)`
- A scrollable bottom sheet created with `ThingSheet.showSheet(...)`

## Run it

From the project root:

```bash
flutter pub get
flutter run
```

This example is a useful reference when integrating the package into your own app.
